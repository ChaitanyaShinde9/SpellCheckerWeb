# Spell Checker using Trie (C + Node + Web UI)

A hybrid project combining a C-based spell checker backend (using Trie data structure)
with a Node.js + Express server and simple HTML/JS frontend.

## How to Run

1. Compile C backend:
   ```bash
   gcc spell_checker.c -o spell_checker.exe
   
2️⃣ Install Node.js dependencies

Run:
npm init -y
npm install express

Start the server:
node server.js
